# Hand-check sheet for clark 0.3.0

Written for the person who looks at the screens after the release. Only what a test cannot decide; everything else is covered by `tests/test_v030.py`. Hand checks never hold up a release.

**Sample data only.** The fictional demo projects. Run `python3 -m clark --demo --open` in the top folder of the release.

Tick each line; write what you saw where it fails.

1. **ask clark answers a real question from the demo data in the real Claude command** (live only; #47). Open ask clark on the demo data, ask 'what is overdue?', and read the answer against the Work items page. [ ]
2. **The ask panel's look (the Wash panel, pills, the working line) is right** (judgement; #102). Open ask clark in light and dark and compare it with the design reference. [ ]
3. **Dragging a card feels right and shows where it will land** (judgement; #68). Drag cards between columns and between lanes on the demo board. [ ]
4. **The launcher opens clark as a Chrome app from a double-click** (live only; #71). Double-click the launcher file; clark opens in its own window; closing it ends clark. [ ]
5. **Word export opens and reads well in Word** (live only; #48). Export a report to Word, open it in Word, and read it as the client would. [ ]
6. **A report filled into your own Word template looks right in Word** (live only; #219). Fill a copy of your own template with {{NAME}} placeholders and open it in Word. [ ]
7. **The Draft email text pastes into Outlook looking right** (live only; #50). Copy a drafted update request and paste it into a new Outlook message. [ ]
8. **Export opens in Excel and Publish arrives in the client folder** (live only; #77). Export, open in Excel; Publish To client and check the folder syncs. [ ]
