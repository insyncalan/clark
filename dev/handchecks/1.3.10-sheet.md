# Hand-check sheet for clark 1.3.10

Written for the person who looks at the screens after the release. One line for each thing a person can see that changed; only what a test cannot decide. Hand checks never hold up a release.

**Sample data only.** The fictional demo projects. Run `bash clark.command --demo` in the unzipped clark folder. Laptop only: Chrome at 1400 px wide, then again at 900 px. Light and dark where a line says so. Do not press Export, Save or Publish on real data.

Each row: what to check by hand, and what you should see. Tick each line; write what you saw where it fails.

Lines are taken from the merged PR texts; words in quotes are the words on the screen. No line was checked by eye when written.

## PR 2264 (row 1275)

- [ ] In Edit, open a Documents and links section. You should see a dashed box under the list with the line "Dropped files are kept in the client folder, in Report files." Check at 1400 and 900.
- [ ] Drag one PDF over the box. You should see "Drop a file here to add it." and a blue border; drop it and see one new entry and one Undo toast. Check at 1400 and 900.
- [ ] Drop two files at once, then a ZIP. You should see "Drop one file at a time.", then "<name>: That type of file can't be added. Use PDF, Word, Excel, PowerPoint, JPG, PNG or TXT." Check at 1400 and 900.
