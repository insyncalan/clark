# Hand-check sheet for clark 0.2.1

Written for the person who checks the screens after the release. It is the short list: only what a test cannot decide, and what 0.2.1 changed. Everything else was checked for 0.2.0 (`0.2.0-sheet.md`) and is covered by the tests. Hand checks never hold up a release; this sheet is for afterwards. Items marked **if it lands** are only there if the fix is in the release you installed: read the release page first.

**Sample data only.** The fictional demo projects. Never use a real client's data for these checks.

## Setup

1. **Install from the download, not from the source.** Download `clark-0.2.1-mac.zip` from the Releases page, unzip it in Finder, and follow the install steps on the release page and in the README. This is the check that matters most: the launcher has to work on a Mac that has never run clark from the source.
2. For the checks marked *(both widths)*: Chrome at 1400 px wide and again at 900 px.
3. For "Your data from 0.2.0": copy your 0.2.0 data folder (`~/Library/Application Support/clark/`) somewhere safe first.

Tick each line; write what you saw where it fails.

## Install and start (live only)

1. **First start.** Double-click `clark.command`. A Terminal window starts clark, then clark opens in its own Chrome window. The prompts your Mac shows the first time are the ones `START-HERE.txt` describes. [ ]
2. **Start it again while it is open.** Double-click `clark.command` a second time. It says "It is already running. Opening its window." and opens another window; nothing breaks. [ ]
3. **It stops by itself.** Close every clark window. About a minute later the Terminal window says clark has stopped. Double-click `clark.command`: it starts again. [ ]
4. **Something else is using the connection** *(if it lands: the new launcher words)*. In Terminal type `python3 -m http.server 8766` (this takes the connection clark wants). Double-click `clark.command`. The message reads plainly: it says nothing was started, why, and what to do (close the other window or program, then double-click again), and it offers a command with another number. Type that command: clark starts. Press Control-C in the first Terminal to stop it. The message has no jargon you would not say to a colleague. [ ]
5. **The doctor.** In Terminal, in the unzipped folder, type `python3 -m clark.doctor`: every line is fine, or says plainly what to fix. [ ]

## The README and the release page (judgement)

## The screens (judgement unless marked live only)

10. **Your data from 0.2.0.** Start 0.2.1 on a copy of the 0.2.0 data folder (`python3 -m clark --data FOLDER`). Every project, work item and milestone is still there, and Settings › Safety lists a backup made at the first start. [ ]
11. **A published file** *(both widths)*. Publish the demo report and open the file. On Work items there is no Add button and nothing that looks editable; the tabs step with Back and Forward. *(if it lands: the dead Add button fix)* [ ]
12. **Edit cells** *(both widths)*. In Edit, change a status, a priority, an owner and a due date in the Work items list. The words do not wrap onto a second line, the date stays on one line, and the cursor stays beside what you type. *(if it lands: the cramped cells fix)* [ ]
13. **Export twice.** In the profile menu click **Export to Excel** twice quickly. One file is saved, the page does not freeze, and clicking again afterwards works. *(if it lands: the export fix)* [ ]
14. **Publish** *(both widths)*. Open the Publish dialog on a project with items that have no owner or date: it lists nothing about them and publishes when you press Publish; the client folder choice and the client checks still work. *(if it lands: the warnings removal)* [ ]
15. **Dark mode** is still pleasant to read on every page *(both widths)*. [ ]
16. **Back and Forward** by trackpad swipe still step through Work items, Milestones and Settings, one page at a time. [ ]
17. **The peek** *(only if the peek is in this release: Alan's call)*. Click a Work items row: a panel opens with the fields and an Activity tab; drag its edge wider and the width is kept. With the peek open, type `//` and "due 5 November, priority high", press Enter: the change reads as from → to, applies as one step, and Undo in the toast puts it back. In View the peek shows fields only. [ ]
18. **The licence and the public pages** (judgement). `LICENSE`, `README.md`, `SECURITY.md` and `NOTICE.md` are in the unzipped folder and read plainly: what you may do, what you may not, and where to write. *(if it lands: the licence and pages)* [ ]
19. **The Work items board** *(both widths, judgement)*. Switch Work items to the board: columns, group by workstream, status, owner, priority and due date, give the board the whole window. In Edit, drag a card to change it; in View nothing is editable. **Preview** and **Export** are in the profile menu. [ ]

## Not in this release
