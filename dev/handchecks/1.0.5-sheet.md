# Hand-check sheet for clark 1.0.5

Written for the person who looks at the screens after the release. Only what a test cannot decide; everything else is covered by `tests/test_v105.py`. Hand checks never hold up a release.

**Sample data only.** The fictional demo projects. Run `bash clark.command --demo` in the unzipped clark folder. Laptop only: Chrome at 1400 px wide, then again at 900 px. Light and dark where a line says so.

Each row: id, what to check by hand, what you should see, and how it is covered. Tick each line; write what you saw where it fails.

## Status of every row

Base: everything merged to main after the tag v1.0.4. The Id is the plan row; the PR is the clark repository's pull request. A row is MERGED, IN REVIEW (a pull request is open or being reviewed), WAITING (not started) or DROPPED. At the cut every row is MERGED or DROPPED. No row has a pull request number yet.
