# Hand-check sheet for clark 1.0.1

Written for the person who looks at the screens after the release. Only what a test cannot decide; everything else is covered by `tests/test_v101.py`. Hand checks never hold up a release.

**Sample data only.** The fictional demo projects. Run `python3 -m clark --demo --open` in the top folder of the release. Laptop only: Chrome at 1400 px wide, then again at 900 px. Light and dark where a line says so.

Each row: id, what to check by hand, what you should see, and how it is covered. Tick each line; write what you saw where it fails.
