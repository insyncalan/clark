# Hand-check sheet for clark 1.0.3

Written for the person who looks at the screens after the release. Only what a test cannot decide; everything else is covered by `tests/test_v103.py`. Hand checks never hold up a release.

**Sample data only.** The fictional demo projects. Run `bash clark.command --demo` in the unzipped clark folder. Laptop only: Chrome at 1400 px wide, then again at 900 px. Light and dark where a line says so.

Each row: id, what to check by hand, what you should see, and how it is covered. Tick each line; write what you saw where it fails.

## Status of every row

Base: everything merged to main after the tag v1.0.2. The Id is the plan row; the PR is the clark repository's pull request, left blank where a row has none yet. A row is MERGED, IN REVIEW (a pull request is open or being reviewed), WAITING (not started or not reviewed yet) or DROPPED (not in 1.0.3: dropped, or moved to 1.0.4). Rows 273, 802, 827, 872, 874, 889, 895, 905, 907, 908, 914, 917, 918, 920, 932 and 941 are MERGED with no visible change, so they have no hand-check row. The macOS gate test fixes (PR 897: the ask clark panel and Appearance arrow-focus waits, the raid card wait, and the scan test split into its own file) have no row of their own and no visible change. Rows 767, 766, 775, 776 and 807 are IN REVIEW because only a part of each has merged (807: the check mark on a Board card is gone, while the list-row half is 1.0.4; 775: the column lift, the rule under the heading, the count pill and the card hover on the Work items board; 776: the floating words box on the Sneak peek, the rest moves to 1.0.4; 767: the Milestones timeline in a printed page and the empty Use cases lines on paper; 766: the peek's four-cell card); each merged part has a hand-check row. Row numbers can be mixed up with pull request numbers: row 830 is the Use cases inline pieces (pull request 813), not pull request 830 (the ask clark Sources list, row 890). A row that merged by a pull request shared with another row (the pull request is named in both) is MERGED in both. The table between the two markers is rewritten from the board export by the regeneration helper; do not edit it by hand.
