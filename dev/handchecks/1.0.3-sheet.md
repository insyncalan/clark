# Hand-check sheet for clark 1.0.3

Written for the person who looks at the screens after the release. Only what a test cannot decide; everything else is covered by `tests/test_v103.py`. Hand checks never hold up a release.

**Sample data only.** The fictional demo projects. Run `bash clark.command --demo` in the unzipped clark folder. Laptop only: Chrome at 1400 px wide, then again at 900 px. Light and dark where a line says so.

Each row: id, what to check by hand, what you should see, and how it is covered. Tick each line; write what you saw where it fails.

## Status of every row

Base: everything merged to main after the tag v1.0.2. The Id is the plan row; the PR is the clark repository's pull request, left blank where a row has none yet. A row is MERGED, IN REVIEW (a pull request is open or being reviewed), WAITING (not started or not reviewed yet) or DROPPED. Rows 273, 802 and 827 are MERGED with no visible change, so they have no hand-check row. Row 767 is IN REVIEW because three of its four faults are open; its merged part (the Milestones timeline in a printed page) has a hand-check row. A row that merged by a pull request shared with another row (the pull request is named in both) is MERGED in both. The table between the two markers is rewritten from the board export by the regeneration helper; do not edit it by hand.
