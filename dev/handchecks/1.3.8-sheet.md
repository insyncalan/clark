# Hand-check sheet for clark 1.3.8

Written for the person who looks at the screens after the release. One line for each thing a person can see that changed; only what a test cannot decide. Hand checks never hold up a release.

**Sample data only.** The fictional demo projects. Run `bash clark.command --demo` in the unzipped clark folder. Laptop only: Chrome at 1400 px wide, then again at 900 px. Light and dark where a line says so. Do not press Export, Save or Publish on real data.

Each row: what to check by hand, and what you should see. Tick each line; write what you saw where it fails.

(origin/main head 3bdb79e67; built from the first-parent merges since v1.3.7. Lines come from the merged PR text; words in quotes are the words on the screen.)

## ask clark (rows 1292, 1331, 1506)

- [ ] Ask a question. On the answer you should see Copy and Ask again. Click in the question box and press the Up arrow: your previous question comes back.
- [ ] With a name in your profile, open Settings, ask clark. You should see a privacy line on the Ask card while the name is saved, and no line when the name is empty.
- [ ] Turn Files off in Settings, ask clark. Drag a file onto the ask clark panel. You should see the browser NOT open the file.

## Published use case page (row 1479)

- [ ] Publish a test file with a use case. Open the use case page. You should see the same layout as the editor's use case page, read only: the Owner shown, no History card and no Last change.

## Rich text editor (row 1364)

- [ ] In any rich text, select words. You should see a font colour button after Strikethrough in the toolbar and in the bubble, with Automatic and named colours; pick one and the words change colour. Check at 1400 and 900, light and dark.

## Milestones and Work items (rows 1329, 1499, 1507)

- [ ] Open Milestones. You should see no "forecast" sentence and no Plan | Movement switch.
- [ ] On Work items, open Columns. You should see the heading "Columns to show" and one line per column with a tick.
- [ ] On Milestones, Calendar view, look at the Timeline / Calendar switch beside Earlier, Later and Today. You should see no overlap, at 1400 and 900.

## Settings and look (rows 1334, 1500)

- [ ] Open the Feedback panel. You should see the text box fill the panel's width, level with the "Added automatically" box.
- [ ] In Settings at 900 to 1099 px wide, look at the sidebar groups. You should see the same spacing as on a wider screen.
