# Hand-check sheet for clark 0.4.0

Written for the person who looks at the screens after the release. Only what a test cannot decide; everything else is covered by `tests/test_v040.py`. Hand checks never hold up a release.

**Sample data only.** The fictional demo projects. Run `python3 -m clark --demo --open` in the top folder of the release.

Tick each line; write what you saw where it fails.

1. **Dragging a section places it full width or beside another, and feels right** (judgement; #96). In Edit, drag a section between rows and onto the left and right half of another. [ ]
2. **The Calendar and Timeline switch reads well, with its icon and word** (judgement; #44a). Open Milestones, switch between Timeline and Calendar, then try Week, Month and Quarter. [ ]
3. **The Excel export opens in Excel with the brand font and frozen header rows** (live only; #85). Export the demo project, open it in Excel, scroll a data sheet and read the Cover sheet. [ ]
4. **An exported Excel file that is edited, saved again and imported still matches its export** (live only; #85). Change a cell in Excel, save, import it, and check the changes listed are only yours. [ ]
5. **Settings > Safety previews and restores a backup** (judgement; #111). Open Settings > Safety, preview a backup and read it; restore only a demo copy. [ ]
6. **Copy diagnostics gives a report with no client content** (judgement; #110). Settings > Logs and diagnostics: choose Debug, work for a minute, Copy diagnostics, read it. [ ]
7. **Each template can be added, the Figures As of box refuses a bad date, and a file can be added to a Documents and links section** (judgement; #96). In Edit, Add a section: add one of each template; type 31-02-2026 in a Figures As of box and read the words; in a Documents and links section add a file and check it is in the client folder's Report files folder. [ ]
