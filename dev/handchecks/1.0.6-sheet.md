# Hand-check sheet for clark 1.0.6

Written for the person who looks at the screens after the release. One line for each thing a person can see that changed; only what a test cannot decide. Hand checks never hold up a release.

**Sample data only.** The fictional demo projects. Run `bash clark.command --demo` in the unzipped clark folder. Laptop only: Chrome at 1400 px wide, then again at 900 px. Light and dark where a line says so. Do not press Export, Save or Publish on real data.

Each row: id, what to check by hand, and what you should see. Tick each line; write what you saw where it fails. The status table and the pull request numbers are Friday's, in the release notes.
