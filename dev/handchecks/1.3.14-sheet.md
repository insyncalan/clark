# Hand-check sheet for clark 1.3.14

Written for the person who looks at the screens after the release. One line per thing a person can see that changed; only what a test cannot decide. Hand checks never hold up a release. Sample data only (`bash clark.command --demo`). Chrome at 1400 px, then 900 px. Light and dark where a line says so.

Only full rows (a done-check marker, and the row's last PR inside the cut) are listed. Lines are taken from the row texts and PR titles; I ran nothing.

- [ ] Dashboard (1266): open a new report's Dashboard: ten sections, the Report headline first, then work items lists for risks, actions and decisions. The health pill and the priority chips are easy to read; light and dark.
- [ ] Excel export (1390): export the demo report to Excel: locked cells are grey, the sheets carry the page colours, and there are Report and Documents sheets. Export the client's copy from the published report: no Latest update column on Actions, Risks & Issues, Decisions or Milestones.
- [ ] Text style menu (1431): open Text style from the toolbar, then from the bubble over selected text: rows of the same height and text size, and the tick on the current style; light and dark.
