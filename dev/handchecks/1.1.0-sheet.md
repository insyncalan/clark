# Hand-check sheet for clark 1.1.0 (Windows, Docker route)

For the person who checks the screens on a real Windows laptop after the release. Docker is already running on the laptop. Use the sample data only: do not press Export, Save or Publish on real data. Tick each line; write what you saw where it fails. Hand checks never hold up the Mac release; the Windows zip is not attached until these lines pass (dev/RELEASING.md).

## Windows lines

| Id | Check | You should see |
|----|-------|----------------|
| 627.1 | Extract the zip into a folder | The clark folder, with no .exe, .cmd or python.exe in it. |
| 627.2 | In PowerShell, type the start commands from START-HERE.md. This line waits on item 624, which adds the Windows commands there | clark starts and says its page address. |
| 627.3 | In Command Prompt, type the same commands | The same result. |
| 627.4 | Extract the zip into a OneDrive folder whose path has spaces, then start | clark refuses, and says in plain words to use a folder outside OneDrive. This line waits on item 635. |
| 627.5 | Add a change, stop clark, start it again | The change is still there. |
| 627.6 | Make a backup, change something, then restore the backup with the typed commands | The earlier data is back. This line waits on item 634. |
| 633.1 | Start the old clark folder, add a change, stop it, unzip the new zip beside it, start the new folder with the up command from docker/UPDATE-windows.txt | The change is still there. |
| 633.2 | When the new clark has a newer data version, start the old folder again | The words "start from the newer clark folder. Nothing was changed." appear in docker compose logs, and docker ps shows the container idle and unhealthy. |
| 633.3 | After the update, open clark-data\backups | A file ending in -migrate.db is there. |
| 633.4 | Type the restore line from docker/UPDATE-windows.txt, then start the old folder | The old clark opens the restored data. |
| 633.5 | Type the Get-FileHash line on the Windows zip | The number equals the one on the release page. |
| 633.6 | Stop the new clark while the data is newer than it, and look at the container under Docker Desktop | The container holds idle (the sh -c command in docker/compose.yaml runs inside the Linux container). |
