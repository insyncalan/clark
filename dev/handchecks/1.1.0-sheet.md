# Hand-check sheet for clark 1.1.0, Windows (Docker route)

Written for the person with a real Windows laptop. Windows runs clark through Docker, not a native build (item 627). Item 623 is the Windows spike; its title says v.0.10, but its done-when is checked on this sheet. Assume Docker is already running, in Linux containers mode. Only what a test cannot decide; hand checks never hold up a release. Tick each line; write what you saw where it fails.

**Sample data only.** Use the fictional demo projects, not real client data.

Each line ends with the v1.1 item id it checks.

## Windows checks

- [ ] Extract the zip with Windows' own "Extract all" into Downloads. The clark folder is complete and nothing is left half-extracted, including the files with long names. (#624)
- [ ] Start clark with the typed commands in PowerShell. The company's PowerShell rules allow them, and clark opens in the browser. (#623)
- [ ] Start clark with the typed commands in Command Prompt. The company's Command Prompt rules allow them, and clark opens in the browser. (#623)
- [ ] Type a data-folder path inside OneDrive with spaces in it, in the Windows form (C:\Users\<you>\OneDrive - Name\clark). clark refuses that data folder and says it is in OneDrive. (#623, #635)
- [ ] Add a project, stop clark, start it again. The data is still there after the restart. (#623)
- [ ] Make a backup. Look for the finished backup in your Windows backup folder (the one mounted as /backups-out); clark copies it there on its own, so do not copy it by hand. Restore it with the typed command `docker compose run --rm clark python3 -m clark restore --from /backups-out NAME`, then `docker compose up -d`. The backup restores and the data matches. (#634)
- [ ] Open clark with Edge, then with Chrome. In each, clark opens as a page in an ordinary browser window (not a standalone app window), and clark says which browser it opened in. (#636)
- [ ] Stop clark and reload the page. The offline page shows and does not show an error trace. (#632)
- [ ] LAN check: from another device on the same network, open the laptop's address on the clark port. clark does not answer. (#638, #623)
- [ ] Save a file. The saved-file wording says where it was saved in plain words, in the Windows path form. (#625, #629)
- [ ] Read a date shown in clark, such as a new item's created date. The date is the day it is on the laptop, in the laptop's own time zone. (#631)
- [ ] Open ask clark. It says ask clark is not available on Windows yet. (#629)
