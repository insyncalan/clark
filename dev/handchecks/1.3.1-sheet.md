# Hand-check sheet for clark 1.3.1

Written for the person who looks at the screens after the release. One line for each thing a person can see that changed; only what a test cannot decide. Hand checks never hold up a release.

**Sample data only.** The fictional demo projects. Run `bash clark.command --demo` in the unzipped clark folder. Laptop only: Chrome at 1400 px wide, then again at 900 px. Light and dark where a line says so. Do not press Export, Save or Publish on real data.

Each row: what to check by hand, and what you should see. Tick each line; write what you saw where it fails. Every line is taken from the merged PR text.

Screens changed since 1.3.0: Settings Theme card, the page and the published file under both Themes, the Work items list (Id, priority, 50 rows, Labels), the peek, the format bubble, the Feedback tag, the timeline grip, the top bar.

## Theme (rows 1269, 1260)

- [ ] Open Settings, then the Theme card. You should see two choices, Classic (default) and Cards, each with one line of words, and a line saying the choice applies the next time the page loads. Pick Cards, reload: the page shows the card look. Pick Classic, reload: the folder look. Check light and dark.
- [ ] Publish a sample project under Cards and open the file; do the same under Classic. You should see the card look in the first and the folder look in the second. Publish again after changing the choice: only the new file changes.

## Work items list (rows 1195, 1222)

- [ ] Open the Work items list. You should see an Id column after Priority, in the link colour on one line, and the priority drawn as a pill (red Urgent, amber High, grey others, a muted dash for none).
- [ ] On a project with more than 50 items, you should see 50 rows and a Show all items link; once open it reads Show only 50. The same choice is in View.
- [ ] Open the column menu and tick Labels. You should see each item's labels in a cell, separated by commas.

## Peeks and rich text (rows 1289, 1288)

- [ ] Open a peek from any list, then open Help. You should see the panel flush to the right edge, under the top bar and down to the bottom of the window, sliding in from the right in about half a second. At 900 px or less it takes the whole width.
- [ ] Select some words in a description. You should see the format bubble with a last button, Draft with AI, that opens the AI menu. It does not appear on a one-line field or when AI is off.

## Feedback, timeline and top bar (rows 1298, 1267, 1239)

- [ ] Open Help, then Settings. You should see a Feedback tag on the right edge that opens a small dialog (Problem, Idea, Question) with the version, the macOS version and the page shown. It is not on the Dashboard, lists, peeks or the published page.
- [ ] On the milestone timeline, drag the grip under the strip and use the arrow keys; Home resets. Print preview should not show the grip.
- [ ] Give a project a very long name (sample data) and resize the window from 1400 to 900 and back. You should see the top bar hold the whole name at once after each resize, not one step behind.
