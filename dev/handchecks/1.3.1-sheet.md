# Hand-check sheet for clark 1.3.1

Written for the person who looks at the screens after the release. One line for each thing a person can see that changed; only what a test cannot decide. Hand checks never hold up a release.

**Sample data only.** The fictional demo projects. Run `bash clark.command --demo` in the unzipped clark folder. Laptop only: Chrome at 1400 px wide, then again at 900 px. Light and dark where a line says so. Do not press Export, Save or Publish on real data.

Each row: what to check by hand, and what you should see. Tick each line; write what you saw where it fails.

Screens changed since 1.3.0: the Feedback tag, the Work items column menu, the report editor leave-save.

## Feedback tag (row 1298)

- [ ] Open Help, then Settings. You should see a Feedback tag fixed to the right edge. It is not there on the Dashboard, a list, a peek or the published page, and not on the Settings Feedback page.
- [ ] Press the tag. The dialog slides in; Problem is picked; Idea and Question can be picked. Copy as text puts your note and the clark version, macOS version and page on the clipboard. Open in your mail app opens a draft.

## Work items list (row 1195, Labels)

- [ ] Open the column menu of the Work items list. You should see a Labels column that you can tick on and off, and the table follows.

## Report editor (row 1277)

- [ ] In the report editor type in a text block, then click on an empty part of the page. Reload. Your text is still there.
