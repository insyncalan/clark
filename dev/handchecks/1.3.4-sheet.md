# Hand-check sheet for clark 1.3.4

Written for the person who looks at the screens after the release. One line for each thing a person can see that changed; only what a test cannot decide. Hand checks never hold up a release.

**Sample data only.** The fictional demo projects. Run `bash clark.command --demo` in the unzipped clark folder. Laptop only: Chrome at 1400 px wide (900 px is next release). Classic theme; Cards must look as before.

(Freeze head main 2d5c4840, 20-11. Rows taken from the merged PR titles.)

## Menus
- [ ] Open any menu near the top of the page. It stays clear of the sticky header and scrolls inside the room left.
- [ ] Menu panels have 10 px corners; the Settings menu panel is soft grey. The Add menu shows a + icon.

## Quick bar and ask clark
- [ ] Press Ctrl/Cmd+K. Roomier rows: name, short hint, kind; taller input.
- [ ] ask clark page tabs are 29 px pills, the chosen one in the brand colour; the first-use card and status line look as designed.
- [ ] Ask about an item that is hidden from the report: the answer can use it. Ask a very broad question: the answer ends with a line saying what was left out.

## Work items
- [ ] Grouped view: heading line, column names once, flat rows. The layout switch has 8 px corners.

## Dashboard
- [ ] Title block, page padding, heading line and section padding as the design. Hide a section: no wrong band is left. Use cases list as designed.
- [ ] Key figures Edit: a live figure is offered only while its section exists.

## Peek and priority
- [ ] Peeks open about 62% of the page wide. A decision shows "made by", "needed by" / "made on". No focus ring on Close when a peek opens without a key.
- [ ] Priority colours: Low green, Medium amber, High red, Urgent maroon, in table and matrix.

## Gantt, Edit
- [ ] The Gantt plan runs the width of the page band in Comfortable spacing.
- [ ] Hide a Tile or Heading in Edit: a text tag says it is hidden.

## Settings
- [ ] Version and updates: Check, download, cancel work; a finished download says it is downloaded and checked.

## Exports
- [ ] A callout with a category, colour and icon: the Word report carries them.
