# clark 0.9.0 (Beta), Mac

Beta means the whole of clark is Beta until version 1.0.

Theme: tidy what 0.8.0 left over, and finish the pieces that were waiting for sign-off.

## What is new

- Export to Word and Import from Word are in the profile menu. Export saves a Word copy of the report and can copy it to the client folder too. Import is there in Edit only: it reads a Word file, shows what it found before anything is added, adds only what you choose, and one Undo takes it all back. The rows it adds are shown to the client until you hide them with the eye.
- Publishing has an Also a PDF tick: the page as it prints, the tabs one after another, no controls, with the publication number in the foot. Your browser's print box opens; choose Save as PDF.
- Work items has Add in View as well as in Edit, and a double-click on a column's grip resets its width.
- The small export arrow beside Use case summary is gone; the Work items workbook export is unchanged.
- The Dashboard's Risks and issues, Open actions and Decisions rows have a status pill, and in Edit each part of a row changes in place, including the wording the client reads (200 characters at most). An Add line adds a row, "Add from your project record" brings one back, and the eye takes one off the page. A published file shows none of the editing.
- About you has an Alias box under your name. It fills in from the name as you type: Jane Doe gives Jane, JD. What you type yourself is kept when the name changes. If you empty it, it stays empty until the page is reloaded, then fills in from the name again.
- Settings, Published reports: each row has Archive. An archived publication leaves the list and the pickers and the toast says "Publication N archived. Restore it from Show archived.". Show archived lists them, each marked Archived with Restore. Archive and Restore are in History; neither can be undone, and neither deletes anything.
- A past publication now opens read only, with a banner that says which publication and day it is and a Back to now link, and a tinted frame round the window. Its checksum is checked when it opens, and a file that no longer matches isn't shown, and clark says why in plain words.
- The bar above the page has a Week ending box in View as well as in Edit. With no week kept it shows the coming Friday and saves nothing until you press Enter on it; a typed day that is not a Friday keeps the old date and says which Friday it needs.
- The project name in the top bar is now always a menu. It lists each project with its number of open items and has Project settings, and it says "Switched to" the project when you change.
- Publish warns while a work item the client would see still has a placeholder title: "1 work item still has a placeholder title (New risk) and will be shown to the client. Rename it or turn off its eye first."
- Settings has a Data card with Export workbook and Import workbook. Import shows what the workbook would change before anything is saved, then imports it in one step, and Undo this import puts it back. Get the template gives an empty workbook with the right sheets and columns. A macro workbook (.xlsm) isn't imported: clark says so and nothing is saved.
- Settings has a Projects table, with Add project, Edit, Archive and Restore.
- Settings, Publishing: the client folder can be pasted as a path as well as picked with Choose folder. A link can't be used: clark says so and points at Choose folder.
- Work items has a "Show archived" pill beside View that shows how many items are archived and remembers your choice for each project. Archived items show in a muted table; one opens in the side panel read only, with one Restore. Restore puts the item back and leaves the panel open on it, now editable.

## What is fixed

- The Not reviewed tile's line now reads, for example, "Not reviewed for more than 14 days, of 8 open items".
- Import from Word now checks on the computer as well as on the page that the file is a Word document.
- In Add a use case, the cursor is in the ID box as soon as the box is drawn, so the first thing typed can't land in the wrong box.
- Moving a card on the board, by dragging it or with its Move to menu, no longer switches the page to Edit.
- In the right-click menu on a row, the hint to select the text and press copy now shows only when some text is selected, and the menu's spacing uses the page's spacing sizes.
- The ring beside Publishing… now keeps turning, at a calmer pace, for as long as publishing takes. It used to stop after about four seconds while the words stayed.
- The High risks and issues tile now counts the open items of the page's Risks and issues type (risks, issues, assumptions and dependencies) rated Urgent or High, by the same rule on the Dashboard and in a published file, so its number and colour are the same in both.
- Clearing a work item's client message now says so in plain words, instead of a server error, and nothing is saved.
- About you: saving your name before clark has finished reading what it already holds no longer blanks your email, and saving your email first no longer blanks your name.

## Behind the scenes

- Groundwork for a later release: code for choosing which model answers a question is in but switched off, with nothing to see on screen.
- The route that suggests text builds its request in one place (nothing to see on screen).
- A publish that replaces a link puts the old one back without a gap, with a link that is not followed, and a platform error is caught.
- Tests and checks only: the generated test pages are built in one shared helper, the rule for which changes run on macOS covers more files, and full test runs on a shared computer take turns.
- Boxes and the side panel put the focus where it belongs before they are drawn, so it can't land a moment late.
