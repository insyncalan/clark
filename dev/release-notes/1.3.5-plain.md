# clark 1.3.5, Mac

This is a fix and polish release on 1.3. It is a full release.

## What is new

### Classic
- Work items table, view tabs and toolbar follow the design; the layout switch tile is 32 px high; the Configure box follows the mock-up; New view is blue.
- Use cases list is drawn as the design shows: measured gaps, grouped-card cell padding and hover colour, + New view in the brand colour, 13 px Next steps, Committed and Planned chips as one muted pill.
- Dashboard: At a glance shows the "of N" note in the figure line; the changed-section sign is a title underline that sweeps and fades; a work-item list in a half-width section gets the row menu and no stray scroll bar.
- Milestones view switch is drawn as designed.
- The Priority line under the matrix says Urgent (Maroon).
- The Ctrl/Cmd+K quick bar lists projects before work items and milestones once you type; the ask row comes first for summarise, check and draft, and the row wraps at 700 px and below.
- The pressed button glow eases in 0.12 s.
- Clicking another row switches the open peek.

### Ask clark
- Ask about this, numbered citations, a Used line and a read line.
- The ask clark page states the size clark really sends: 300,000 tokens, with no per-question cost cap.
- Usage in tokens, this month's questions and tokens per project.
- Settings: slash commands have a list and an editor page, opened in a new tab.
- Used from All projects card and Model row (Settings).
- The Used line names the connector only; each connector used is logged, and turning a connector Off stops a question running on it.
- A name-only scan warns of people or contract words in a source folder (the warning screen itself is not in this release).

### Settings
- The Feedback tag mail button opens through the open-mail route.

### Weekly report
- The report pill says "Include in the weekly report".

### Help
- Help says the Theme changes the pages, not the Word, Excel and email files or the installed app.

## Known limits
- On Use cases, Commitment, Release and On the dashboard all on at once still leave the Use case column too narrow; turn one off.
- Checks were made by reading the code; I did not see a running page.
