# clark 1.0.1 (Beta), Mac

This is the 1.0 build. It is still marked Beta because updating from inside clark is not switched on yet.

This version includes a change to how clark stores your data. Read this first.

## Read this first: a change to how clark stores your data

- One change to the data file format (from layout 15 to 16). clark makes a safety copy of your data before it changes anything.
  - Step 16: each use case can now carry a flag, Candidate, Committed or Planned 2027. Every use case you already have starts with no flag, so nothing you see changes.
- An older clark (1.0.0) refuses the new data file: "This data needs a newer clark. Nothing was changed. Install the latest clark, then try again." Once this version has opened a project file, open it only with this version or a newer one. To go back, restore the safety copy clark took before the change.
- Updating from inside clark is not switched on yet: install a new version by downloading it and replacing the old one.

Theme: ChatGPT and Claude on the Settings AI card, Excel in and out, and a steadier Dashboard and Settings.

## What is new

- Settings has an AI card: connect Claude or ChatGPT and ask clark uses it. The card has a tile for each, saying Connected or Not connected, with a Connect or Disconnect button, and a Model for ask clark list; if you choose a smaller model, the card asks first (Use it anyway or Keep the model I have). No password is asked for: the Claude or ChatGPT command already signed in on this computer is the one used, and what you ask goes to the one you use.
- A use case can carry a Commitment flag: Candidate, Committed or Planned 2027, or no flag. A new use case starts with no flag, and the use cases you already have show nothing until you set one. In Edit a small Commitment menu beside the status has the three words and No flag. The flag shows as a chip beside the status on the Use cases tab and in the Dashboard rows, and the client sees it in the published report; the eye still hides the whole use case. The Word copy's use case table has a Commitment column. History shows "changed the Commitment from X to Y", and Undo puts it back. The Excel export has a Commitment column after Status with a drop-down of the three words; on import a wrong word is reported by row and an empty cell leaves the flag as it is.
