# clark 0.5.2 (Beta), Mac

Beta means the whole of clark is Beta until version 1.0.

Theme: numbered publications, which include a database change, and corrections to the 0.5.1 notes. A short list from the changes since 0.5.1.

## Read this first: a database change

- Numbered publications (#120) include a database migration (step 10). Each publish gets a number, kept per project, and the number is never reused.
- An older clark refuses the new database. Once 0.5.2 has opened a data folder, open it only with 0.5.2 or newer. A safety copy of the data is made before the change.

## What is new

- Numbered publications: each publish gets a number. It shows in the success message and in the footer of the published file. Local copies and Word copies share the same count.
- Progress tracker template, pieces 3 and 4 (#189): the totals and the editor.
- Project health sits on its own row at 1180 px and below.

## Corrections to the 0.5.1 notes

- In the editor, the tab is called "Client Requested Report View" (the 0.5.1 notes said "Client report"). A published file shows it to the client as "Weekly snapshot".
- 0.5.1 also made the week-ending date on the report bar editable, in View and Edit. The 0.5.1 notes did not say so.

## Also in this version (checks and tests, nothing you see)

- The CI scan now accepts a team branch name in a commit message.
- Tests: the speed tests judge against a baseline taken in the same run, not a fixed second; the native-program tests no longer depend on the runner's temp folder; near-miss system prompts are refused.
