# clark 0.11.0 (Beta), Mac

Beta means the whole of clark is Beta until version 1.0.

Theme: Import from Excel on Work items, the Update card, and clearer prompts on a use case.

## What is new

- Work items has an Import from Excel icon. Pick a workbook and clark shows a Check the import screen: a counts row, a line for each sheet, and Accept or Reject on every row, with Accept all and Reject all. If any row breaks a rule, the whole file is turned down and nothing is stored. The Data card in Settings carries the same note in the same words.
- The Update card in Settings is now called Version and updates and has labelled rows: Installed, Update, Install from a file and Last update. Under them are three short lines: "Download the new version from the clark releases page, then choose it below.", "Version X is ready to install." and "The update attached to the release for your computer. Keep its .sig file in the same folder." Updating from inside clark is not switched on yet, so for now a new version is installed by downloading it and replacing the old one.

## What is changed

- On a use case, the empty Where it stands boxes now say what to write. The headline box says "Today's position, in one line" and the text box says "What is done, what is happening now, and what is next. Add anything that is blocked or at risk." On the read-only page an empty headline shows "No headline yet".

## Behind the scenes

- The first-project fix, the editors and the top bar from 0.10 are unchanged.
- The Polish hint in the prototype's Improve menu now wraps inside the menu. This is the design prototype only; the app has no Improve menu yet.
- The Help entries for the Update card are written but kept out of sight until updating from inside clark is switched on.
