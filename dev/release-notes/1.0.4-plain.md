# clark 1.0.4 (Beta), Mac

This is the 1.0 build. It is still marked Beta: it works and is tested, but expect rough edges and changes between versions.

This version includes a change to how clark stores your data. Read this first.

## Read this first: a change to how clark stores your data

- One change to how your data file is stored. A safety copy of your data is made before anything changes.
  - A project can now hold Gantt lines, and keeps its Gantt settings: whether the Gantt shows to the client, the name of its tab, its title, the columns left out of a client file, and the rows it opens with. A project with no Gantt lines looks as it did.
- An older clark (1.0.3) will not open the new data file: "This data needs a newer clark. Nothing was changed. Install the latest clark, then try again." Once this version has opened a project file, open it only with this version or a newer one.
- Going back to 1.0.3 means putting back the safety copy clark took before the change. It is listed as "before an update" in Settings, Backups, where Preview and Restore are beside it. Or, with clark closed, type `bash clark.command restore` in the clark folder to list your copies and put one back. First restore the safety copy, then open it with 1.0.3.
- Updating from inside clark works from 1.0.3 to this version. It takes the safety copy first.

## What is new

- The Gantt. A project now keeps its Gantt lines: a name, a start and an end, an owner, effort, budget, a baseline and a note for each line. A line with its eye off never reaches a client file.
- The Excel workbook from the editor has a Gantt sheet with every line. The client workbook has a Gantt sheet with only the lines the client may see, and none of the columns left out of a client file.
- Import from Excel reads the Gantt sheet. You tick it in the import form, as you tick the other sheets. The change is one step with one Undo. If a row of the Gantt sheet breaks a rule (a bad date, Done over 100, a parent that is not a phase, or more than 500 lines), none of the file is imported and the message gives the rule and the row number; untick the Gantt sheet to import the other sheets. A row whose ID belongs to another project, or is not written as a full Gantt line ID, is left out and named, and a second row with the same ID is left out. The client workbook is not a workbook to import: clark says so and reads nothing from it.
- Add a section now offers two more templates: Current state and Plan summary. A new section with a starting text is one change with one Undo.
- A progress tile shows what is achieved against what is planned (for example Achieved 45% Planned 50%). Its status words can be edited, and its template settings carry a Size.
- A published file draws the progress tile, with its table of lines, and the columns of numbers and dates are wide enough to read.
- The Work items view menu offers Rename and Delete for any saved view, the built-in tabs included.
- The Sneak peek card shows the words you typed as chips in the order you typed them, with Not now and Make the change below.

## What is changed

- The Publish box lists Word before PDF. Option titles are in the medium weight and the box is 560 px wide.
- The base text is 15 px, with a line of 22.5 px (the published file too).
- Saved views are deleted, not archived: Delete replaces Archive and Bring back. Views you archived in 1.0.3 stay stored in your file but can no longer be reached from the view menu.
- In the dark theme the main buttons read at 4.5 to 1 and the focus rings show at 3 to 1.
- Menus fade out as they close. With reduced motion on, they go at once.
- The two decorative one-side stripes in the ask panel (the passage, and the suggested change) are quieter.
- In Edit, the owner name of a work item stays on one line, with an ellipsis when it is too long.
- The update check accepts START-HERE.md or START-HERE.txt as the one start file in an update zip.
- The message for an update with a missing signature part says what is wrong and what to do.
- The Help pages say that the Excel export and import carry a Gantt sheet, and what the import does with a line that breaks a rule.
- Owner is left out of a client Gantt unless you show it. A project that already has a saved setting keeps it.
- The chosen half of a segmented control has a dark focus ring, and menus have a stronger border; both also show in a published report.

## What is fixed

- On Work items, the list of filter suggestions sits under the message line and no longer covers it.

## Known limits

- To move from 1.0.3 to 1.0.4 you can update from inside clark. From 1.0.2 or earlier, install by hand: rename the old clark folder first, then unzip the download into a fresh empty folder. A plain unzip over the old folder merges old and new files.
- Editing a demo project keeps it: Remove demo data takes away only the demo projects you have not touched.
- A Gantt sheet with more than 500 lines stops the import; split it into smaller sheets.
- The client workbook is a copy for the client. It cannot be imported back.
- In the client workbook only the ID, Original and Shown state are locked, and Priority on the Risks & Issues sheet; the text cells stay editable, by design.
- Sorting is blocked on a protected sheet.

## Updating

- Updating from inside clark works from 1.0.3 to this version. To move from 1.0.2 to 1.0.4, install by hand as described under Known limits, because 1.0.2 cannot update itself.
