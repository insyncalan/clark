# clark 1.0.0 (Beta), Mac

This is the 1.0 build. It is still marked Beta because updating from inside clark is not switched on yet.

Theme: a new Help, with a start page, step-by-step guides with pictures, search that shows where the words are, and a short help text for every screen.

## What is new

- Help has a new Start here page. It shows five jobs: Add a work item, Write this week's report, Add a section from a template, Move, hide and delete sections, and Publish to the client. Each one opens its steps. A contents list stays in view while you read and marks where you are, each guide ends with a What next list, the Back button takes you back to the screen you were on, and a Back to button returns you to the entry you read before.
- Nine how-to guides, each with numbered steps and a line saying what you should see at the end: Add a section from a template; Move, hide and delete sections; Bring in an Excel workbook; Send the workbook out; Publish to the client; Hand an item over; Save a view; See the Dashboard as it stood on a past day; Back up and restore your data.
- 13 pictures in the guides that show the screen a step is about: the template box, the section menu, the Excel icons, the publish menu and others. They are taken in the Light theme only.
- Search in Help now shows where the words are. Each result from a guide names the guide and the step it is in.
- Press ? on the Dashboard (view or Edit), Work items, Milestones or Settings, or tap the ? in the top bar, and a Help peek opens beside the page with a short text for that screen. On Settings it also has one short line for each card. Open full Help at the foot of the peek goes to the full Help. The peek is in the editing pages only; a published report has none.
- Help has an entry called Run clark with Docker, in the Advanced group. It covers installing Docker Desktop, starting and stopping clark, changing the port, using the projects you already have, and what to do when the page will not open.

## What is changed

- When clark runs in Docker on a port of your own (for example CLARK_PORT=8800), the line it prints for opening clark names that port.

## Updating

- Updating from inside clark is not switched on yet: install a new version by downloading it and replacing the old one.
