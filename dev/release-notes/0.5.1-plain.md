# clark 0.5.1 (Beta), Mac

Beta means the whole of clark is Beta until version 1.0.

Theme: a client report tab in a published file, two fixes found when 0.5.0 was checked by hand, and the smaller changes made since 0.5.0.

## What is new

- A published file now has a Weekly snapshot tab: the client report view, with a dark cover band. It shows no item ids, no Escalate line and no placeholder lines such as "Not set" or "Nothing written yet"; a part with nothing to say is left out. (In the editor the tab is still called Client report.)

## What is fixed

- A click on a tab in a published page no longer clears a client's saved Work items filters. The choices you made come back when you open Work items again. Clear all still clears them.
- "Use cases" is written in sentence case everywhere a person sees it, in the editor and in a published file (it was "Use Cases" in the published tab and heading).

## Also in this version

- Milestones: each row has an eye, in the editor, to leave it off the published page, and rows now sit on one line.
- Milestones: Show archived lists the archived milestones, and Restore, in the editor, puts one back in one step, with Undo.
- Starting clark: when something goes wrong, the launcher says what happened and gives one next step.
- Only one clark can run on a data folder. A second one started on the same folder is refused, and the message says why and what to do.
- Settings, Logs and diagnostics: the Errors list is in plain words. Copy diagnostics still keeps the full detail.
- "Too big to save" now says what to do: make the text shorter, or take some of the list out.
- Clearer refusal words. When text with a password or a key in it is not sent, clark says: "That looks like a password or a key, so it wasn't sent. Take it out and try again." A file left out of an answer for the same reason now says what to do next.
- In Draft email, when "I sent it" is refused, you see clark's whole sentence, not a cut-off one.
- Passwords and keys: a quoted password made only of letters is now caught, and ordinary file names and words are no longer refused by mistake.
- Ask clark: a reply that holds a key or a password is held back, and a passage that looks like a key is left out of what is sent.
- Excel export: text that looks like a formula is kept as text.
- Templates: if an Undo of a linked change can only be partly done, the message says what was put back and what was not.
- In the editor, a section's move handle no longer runs into the Title box, and on a narrow window it sits in the card's padding.
