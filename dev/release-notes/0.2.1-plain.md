**Version 0.2.1 of clark (Beta): a tidy-up after 0.2.0. Released [date]. Mac only.**

The whole of clark is **Beta** until version 1.0: it works and is tested, but expect rough edges and changes between versions.

This version fixes small things found while checking 0.2.0, and makes a few messages easier to read. Your data and your files are not changed: you can start 0.2.1 on the same data folder as 0.2.0.

*The peek* [in the scope; include when #221 is merged]
- **The peek.** Click a row and a panel opens beside the list with that item's fields and its Activity (who changed what, and when). Drag its edge to make it wider; clark remembers the width. Click another item and the panel moves to it. Back closes it first.
- **Sneak peek.** With the peek open, type `//` and describe a change in plain words, for example "due 5 November, priority high". clark shows what would change, from and to. Press Enter to apply it as one step. A toast offers Undo.

*The licence and the public pages* [in the scope; include when the docs change is merged]
- **A licence.** clark now has a `LICENSE` file. You may read the code, and download and run clark for your own work, including reports you make for your employer or your clients. You may not copy it, change it or build on it without permission. To ask for permission, write to the address in the file.
- **A README, a security page and a list of the other people's code clark includes** (`NOTICE.md`), so it is clear where to report a problem and who made what.
- **Every change offered to clark's public home is now checked automatically** for passwords, private names and files that should not be there, before it can be accepted. [in the scope; Alan approved it 31-10-2026; include when its pull request is merged]

*Also there since 0.2.0, but not named in its notes*
- **The Work items board.** Switch the Work items list to a board with columns, group by workstream, status, owner, priority or due date, drag a card to change it (in Edit), and give the board the whole window. **Preview and Export** are in the profile menu, and the Help has a short guide to the board.

*Publishing*
- **The Publish dialog no longer warns before it publishes.** The list of work items with no owner or date, and of items not reviewed for a while, is gone: you press Publish and it publishes. The checks on the finished file (hidden rows, rows not marked for the client, Sensitive rows, internal notes) are unchanged. [Alan 31-10-2026; include when merged]

**Install (Mac):**
1. Download `clark-0.2.1-mac.zip` below and unzip it (double-click it in Finder).
2. clark needs **Google Chrome** and Python 3.9 or newer. To check your Mac is ready, open **Terminal** (the app called Terminal, in Applications › Utilities), type `cd ` (with a space), drag the unzipped folder into the Terminal window, press Return, then type `python3 -m clark.doctor` and press Return. It tells you what to fix, if anything, and where to get it.
3. Double-click `clark.command`. The file `START-HERE.txt` in the folder explains the prompts your Mac may show the first time.

Keep clark's data folder outside OneDrive. If you use 0.2.0 or 0.1.0 with real data, copy your data folder somewhere safe before you start 0.2.1.
