# clark 1.3.0, Mac

This is the 1.3 build. It follows 1.2.0 and is the first cut of the 1.3 line.

## What is new

### Work items list

- In the Work items list, the Priority drop-down of a risk or an issue opens the same Impact by Likelihood grid as the peek. Click or Enter or Space picks a cell, the arrow keys move and stop at the four edges, and Esc or a click outside closes it with nothing changed. Both fields change in one step. An action or a decision keeps its plain list.
- The filter chips are rounded rectangles in the loaded brand colours, with a remove cross that follows the chip text colour. Plain-word chips stay grey.

### Menus

- Group by has its heading in capitals, a tick before the icon and a panel at least 14 rem wide.
- Move to lists every column the card can go to and the column it is in now, ticked and not a choice. It opens to the left when the card is in the right-most columns, so it no longer runs past the window.
- The Add milestone, Add project and Add use case openers take the dashed look of the Add opener on Work items.
- A right-click on a Dashboard list row (risks, actions, decisions) opens the Work items row menu, with the same entries. The menu key and Shift+F10 open it too, and Escape returns to the id button. A long unbroken word in an entry wraps inside the menu.

### Settings

- The Settings menu shows what is a group heading and what is a page. Headings are small, muted capitals and are not clickable. Page rows are 32 px high, with a hover fill, a pointer and the open page marked. Copying a heading gives its capitals.

### Report header

- The project name in the editor header and in the published bar is never cut with an ellipsis: it wraps, even a single long word, and the bar grows to hold it (at least 85 px high, 129 px at 900 px wide).

### Use cases and drag

- The rows box on a use case page refits when its size or the fonts change. A drag ends when its grip is gone.

## What is changed

- The README and the README in the download open with "Version 1.3. clark runs on a Mac. On Windows, unzip the same download and run clark in Docker; the release notes say how."

## Windows

The Windows download is a zip, not a native build. You unzip it and run clark in Docker.
