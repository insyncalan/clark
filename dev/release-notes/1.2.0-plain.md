# clark 1.2.0, Mac

This is the 1.2 build. It is a full release.

## What is new

### Work items list

- The Work items list section holds live rows from Work items, chosen by a filter. Its saved views are tabs above the list, with a dot and "Save view" or "Discard changes" when the list has moved off the tab, and "+ New view". An Add menu sits at the right end of the saved-views row.
- Configure on a list sets Sort by, Most rows, Columns and a Footnote. The rows scroll, with a line "Showing N of M" and a "Review all N items" link that opens the Work items page on the right type.
- A right-click on a column heading opens a "Columns" menu of checkable columns. A list uses the page's own filter box, and a row opens a read-only peek. Rows can be edited in place and columns have widths.
- A Decisions list reads "Open, and decisions made in the last 14 days". A row with no rating says "Not rated".
- The At a glance tiles in the Word report count only rows that a shown section or a list reaches.
- A list keeps its own rows when the built-in Actions, Risks and issues or Decisions section is hidden. Sensitive, client-off, archived and eye-hidden rows stay out.
- The Word report and the client workbook print a Work items list as one table. A list that chose no columns prints Type, ID, Item, Owner, Due, Priority; other columns are Status, Workstream and Milestone. A row due the day before the as-at date says "Yesterday" and a later one says "N days late". A decision gets the late words only while its status is Pending.

### Project at a glance

- A new section, Project at a glance, is in the library under Figures (full width or half). It shows the project health tile and the three counting tiles (Overdue actions, High risks and issues, Decisions needed), then your own tiles. A counting tile is left out when it has no rows. In View a counting tile opens Work items with that filter; your own tiles are plain.
- In Edit each built-in tile has a grip (drag it, or Alt with the arrow keys) and an eye that hides it from the published report. Project health can take a row of its own, and "Tiles on a line" is 3 or 4 (half width always shows 2). The three counting tiles have a right-click outline colour menu. Each change is one step and one Undo. When every tile is switched off the section says "No tiles on this section."
- You can add your own tiles (up to 12): Add a tile, a pencil, Done and Cancel, Remove tile. A tile has a label (40 characters), a figure (12), a tag (12) and a note (60). Five colours, each with its own shape: Green circle, Amber triangle, Red diamond, Blue square, Neutral ring.
- The Word report prints the section's tiles on a line, as many as the section shows; the client workbook has one sheet per Project at a glance section with the heads Label, Figure, Tag and Note. Tile words stay text in the workbook.
- Help has a row for it.

### Callout

- A Callout has an optional category (30 characters at most), a colour (Plain, Violet, Amber, Red, Green or Grey), an icon (20 named icons or No icon), and a Tile and a Heading you can switch on or off. Older callouts open unchanged.
- In View and in a published page the Callout is a tinted box with its icon and category word, and no stripe; Plain has no box. In Edit the toolbar reads Category, Colour, Icon, Show, Tile, Heading, with "Title N of 120" counting characters.
- The Callout sits in a new library group, Project information. The Tile and Heading switches show an eye icon, open when on and struck through when off.
- A published Callout names its colour and icon in words for a screen reader, for example "Colour: Violet. Icon: Light bulb."

### Peeks

- The Latest update is one bordered card with a footer strip inside it ("⌘ Enter to save", always shown) and a stamp under it ("last updated dd-mm-yyyy hh:mm"). The placeholder reads "What changed? Add the latest update…".
- The Rating chip's level pill is bold and its icon takes the colour word's tone. The rating matrix for a risk and an issue has a Low, Medium, High row of headings under the grid, and both use the tip "Priority from impact and likelihood".

### Use cases

- The Owner line in Details on a use case page is a box. Enter or leaving the box saves it as one change with one Undo; Esc puts the old owner back. More than 200 characters is refused and the old owner is kept. A published page still shows the owner as text.

### Gantt

- The Table word button is gone. Two icon buttons, table and chart, take its place beside the Week, Month and Quarter switches (in the table view they sit in the page bar). Zoom out, the percentage and Zoom in sit beside the Show filter, with Today and full screen after it. A chart view with no View or Edit button no longer draws an empty bar above the chart bar.

### Published page

- In a published report, a click or Enter on a picture in an Image gallery opens it larger, with its caption. Esc, a click outside it or the close button closes it.

## What is changed

### Dashboard

- The default report no longer starts with a Summary section: the default list goes from eleven sections to ten, and Current state is the first. Existing projects keep their own Summary.
- Help now says "Click the text under Current state, This week or Next week", and the sections table row reads "Current state, This week, Next week". Help also lists the new Project information group.

### Filter line and saved views

- A changed view, core views included, shows "Update view" (it was "Save changes"). Leaving the filter line with unsaved changes asks "Save your changes to this view?" with three buttons: "Update view", "Save as a new view" and "Discard". Clicking inside the filter box does not ask. Help is reworded to match and says the five standard tabs are updated for this project only.

### Published page

- The project name in the bar of a published report is drawn in the brand heading face on every tab (Dashboard, Work items, Use cases, Milestones). Its size, weight and colour are unchanged.

## Windows

The Windows download is a zip, not a native build. You unzip it and run clark in Docker.
