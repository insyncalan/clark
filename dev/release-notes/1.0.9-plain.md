# clark 1.0.9 (Beta), Mac

This is the 1.0 build. It is still marked Beta: it works and is tested, but expect rough edges and changes between versions.

## What is new

### Dashboard

- A new project starts with a blank Current state box at the top of the Dashboard. While you edit, a short line suggests what to write; it is not saved and does not appear on the published page.
- In a new project, Summary, This week and Next week also start blank. Each shows its own short suggestion while you edit; it is not saved and does not appear on the published page.

### Work items

- The Caption box moves under the list in the Work items edit panel, and each listed row has the client eye, as on the Work items page. Hiding an item with the eye also hides it elsewhere on the published page. When every listed item is hidden, the section says "Every work item listed here is hidden from the client, so this section is left out of the published page. Turn an eye on to list one."
- A peek now opens 640 px wide in a window 1000 px or wider and keeps the width you last dragged it to; in a narrower window an item or milestone peek is full width. It can be dragged as wide as the window minus 32 px.

### Milestones

- The hover or focus tip of a milestone mark whose label is hidden is drawn whole: above the shown labels and inside the timeline box.

### Settings

- Command+Option+S opens Settings, on a Mac, in View and in Edit, when you are not typing in a field and have no dialog, menu, peek or Help open.
- A Skip to settings button comes right after the search box; it is hidden while a search is showing.
- Spacing, the Gantt boxes and the Feedback box show the same focus ring as the other fields.

### Excel

- A full Excel export carries a hidden sheet, locked against editing, of information that clark reads back as information only. It does not show in Excel's Unhide list.

## What is changed

### Dashboard

- Choosing another project from the project name in the header reloads the whole page for that project: its work items, milestones, data and brand all change, and the first project's items do not show under the second.
- On the Dashboard, the top bar and the banner are now one slim header that stays at the top as you scroll. It shows the project name, which is a button: its tip says "Click to change project", a click opens the project list and a second click shuts it. It also shows the week, which is a button that opens the calendar. The View and Edit icons float just under the header, at the right. The Gantt page keeps its banner, and a published report keeps its own top bar.

### Settings

- The Settings page has a new look: soft side-menu rows with a violet marker on the card you are reading, fields, buttons and choices edged in one colour, example text in empty boxes, the Backups path as a line of text with a short Use button beside it, and one set of text sizes. The Gantt card looks as before.
- The Motion switch says its new state in a quiet message with Undo, like Spacing and Appearance.

### Work items

- The duplicate ... (More actions) button is removed from the end of every Work items row. The eye stays, the right-click menu stays, and the Menu key on a focused row still opens the menu. The button stays on use case rows, milestone rows and in the peek.
- Move, drag and Add after skip a stored Needs from you section, so they count only the sections shown.

## What is fixed

### Version check

- A pre-release path (v1.0.8-rc10) now sorts below its release (v1.0.8) and above the previous version; build names such as -arm64, -amd64 and -bin are not pre-release.

### Excel

- The Excel export file name no longer ends in a dot or a space before the code or the date when the project name is cut.

### Behind the scenes

- Several tests that failed on a Mac or on a slow machine now wait properly, and tests on a shallow copy of the code fetch the release tags first.

## Known limits

- Editing a demo project keeps it: Remove demo data takes away only the demo projects you have not touched.
- A Gantt sheet with more than 500 lines stops the import; split it into smaller sheets.
- The client workbook is a copy for the client. It cannot be imported back.
- Sorting is blocked on a protected sheet.
- To move to 1.0.9 from 1.0.6 or earlier, install by hand: the update inside those versions does not accept this download. Quit clark first, then rename the old clark folder. Then unzip the download into a fresh empty folder. A plain unzip over the old folder merges old and new files. Your projects stay where they are. From 1.0.7 or later, update from inside clark.
