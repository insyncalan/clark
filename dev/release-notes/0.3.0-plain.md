**Version 0.3.0 of clark (Beta): AI and communication. Released [date]. Mac only.**

The whole of clark is **Beta** until version 1.0: it works and is tested, but expect rough edges and changes between versions.

## What is new

- An AI menu in every editor: select text and ask for a suggestion. Nothing changes until you accept it, and accepting is one step with Undo.
- The Claude command is used with stricter safeguards, so the AI menu only ever reads the text you selected.
- The Word report can fill your own template. Put {{NAME}} placeholders in a Word file and clark fills them.
- Word export and Word import have their own route, with a step that checks the file before anything is changed.
- Draft email tone steps read First chase, Second chase and Firmer chase.
- Dates in the Draft email are read in one format only (YYYY-MM-DD), the same on every computer.
- If the port is taken, the launcher message names the right program off a Mac and says "window or program".

## Not yet

ask clark (the question box) is not in this version. Signing in to Claude or OpenAI from inside clark is not in. The Draft email is not yet written inside the editor (update request, chase and decision request). The Work items board with Group by, the full-screen board, owner, due, priority and status changed in place in the table, Publish, Preview and Excel export in the profile menu, and clark as a Chrome app are not in.
