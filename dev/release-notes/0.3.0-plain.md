# clark 0.3.0 (Beta), Mac

Beta means the whole of clark is Beta until version 1.0.

Theme: AI and communication, and safer undo.

## What is new

- An AI menu in every editor: select text and ask for a suggestion. Nothing changes until you accept it, and accepting is one step with Undo.
- The Claude command is used with stricter safeguards, so the AI menu only ever reads the text you selected.
- A key or a password typed into a question, or inside the text you selected, is refused before anything is sent.
- The question panel has a new look.
- Text read from your source folders is checked for passwords and keys before anything is sent. A file that looks like it holds one is left out, and the panel says how many files were left out for safety.
- Undo several changes at once, and select several work items.
- The Word report can fill your own template. Put {{NAME}} placeholders in a Word file and clark fills them.
- Word export and Word import have their own route, with a step that checks the file before anything is changed.
- Draft email tone steps read First chase, Second chase and Firmer chase.
- Dates in the Draft email are read in one format only (YYYY-MM-DD), the same on every computer.
- If the port is taken, the launcher message names the right program off a Mac and says "window or program".
- A font list that points outside the fonts folder is refused when the page is built.
- Refused requests no longer flood the diagnostics log.
- The checks on image and font files run before each release are stricter.

## Not yet

Signing in to Claude or OpenAI from inside clark is not in this version. PDF files in your source folders are not read yet, and the panel says how many were skipped.
