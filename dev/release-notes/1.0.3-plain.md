# clark 1.0.3 (Beta), Mac

This is the 1.0 build. It is still marked Beta because updating from inside clark is not switched on yet.

This version does not change how clark stores your data. Your project files open as they did in 1.0.2.

## What is new

Nothing you can see has changed yet. A line is added here only when its change has merged into main and a person can see it.

## Known limits

- Updating from inside clark is still not switched on. To move from 1.0.2 to 1.0.3, install by hand: rename the old clark folder first, then unzip the download into a fresh empty folder. A plain unzip over the old folder merges old and new files.
- Editing a demo project keeps it: Remove demo data takes away only the demo projects you have not touched.

## Updating

- Updating from inside clark is not switched on yet: install a new version by downloading it and replacing the old one.
