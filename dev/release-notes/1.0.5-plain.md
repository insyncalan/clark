# clark 1.0.5 (Beta), Mac

This is the 1.0 build. It is still marked Beta: it works and is tested, but expect rough edges and changes between versions.

## Read this first: your data file is not changed

- This version does not change how your data file is stored. It stays at the layout 1.0.4 uses, so 1.0.4 can still open it.

## What is new

- The Settings Data card has an Excel file layout (preview) button. It shows how the workbook is laid out and does not export or import anything.
- The zip holds one start file, START-HERE.md. The update check still accepts START-HERE.md or START-HERE.txt.
- Rows added to or removed from a list fade in or fold away. With reduced motion on, they change at once.
- The Gantt bars grow in from the left once each time you open the page or change the data folder. They do not grow again when you return to the tab. With reduced motion on, they appear at once.

## What is changed

- The View | Edit switch is on the Dashboard and the Gantt page only, and the E and V keys work on those two pages. No other page has the switch.
- The other pickers and menus fade out as they close, as the menus did in 1.0.4, including the Report menu in a published file. With reduced motion on, they go at once.
- Excel import stops a workbook that is too large to read safely, and says so.
- A file you publish is checked for Gantt details that must stay out of the client's copy.

## What is fixed

- A second Esc, or a shortcut key, pressed while a menu is closing is no longer ignored.

## Known limits

- To move from 1.0.4 to this version you can update from inside clark. From 1.0.3 or earlier, install by hand: rename the old clark folder first, then unzip the download into a fresh empty folder. A plain unzip over the old folder merges old and new files.
- Editing a demo project keeps it: Remove demo data takes away only the demo projects you have not touched.
- A Gantt sheet with more than 500 lines stops the import; split it into smaller sheets.
- The client workbook is a copy for the client. It cannot be imported back.
- Sorting is blocked on a protected sheet.

## Updating

- Updating from inside clark works from 1.0.4 to this version.
- From 1.0.3 or earlier, install by hand as described under Known limits. The 1.0.3 update check knows only START-HERE.txt and stops an update that carries START-HERE.md.
