# clark 1.0.5 (Beta), Mac

This is the 1.0 build. It is still marked Beta: it works and is tested, but expect rough edges and changes between versions.

## What is changed

- The data file moves to layout 20. An older clark (1.0.4) will not open it and says: "This data needs a newer clark. Nothing was changed. Install the latest clark, then try again." A safety copy of your data is made before anything changes. It is the way back: it is listed as "before an update" in Settings, Backups, where Preview and Restore are beside it.
- The View | Edit switch is shown only on the Dashboard and the Gantt page.
- A row added to a list fades in, and a row taken away fades out. With reduced motion on, they change at once.
- The Gantt bars grow in from the left once, when the page opens. They do not move again when you drag, resize, select or filter. With reduced motion on, they do not move at all.
- When clark is already running from another folder or another version, starting this one tells you so, changes nothing and says how to quit the other one (press Ctrl+C in its Terminal window).
- The download holds a start file named START-HERE.md, where 1.0.4 held START-HERE.txt.

## What is fixed

- A second Esc pressed while a menu is still fading out now closes the menu in Board, Hand over and Bulk, where it was ignored.
- Import from Excel stops a workbook that declares a huge sheet or holds one very large cell, instead of using up the memory of the computer.
- The focus ring on the View | Edit switch can be seen in dark mode.

## Known limits

- To move to 1.0.5 from 1.0.4, update from inside clark. From 1.0.3 or earlier, install by hand: the update inside those versions does not accept a download that holds START-HERE.md. Quit clark first, then rename the old clark folder. Then unzip the download into a fresh empty folder. A plain unzip over the old folder merges old and new files. Your projects stay where they are.
- Editing a demo project keeps it: Remove demo data takes away only the demo projects you have not touched.
- A Gantt sheet with more than 500 lines stops the import; split it into smaller sheets.
- The client workbook is a copy for the client. It cannot be imported back.
- Sorting is blocked on a protected sheet.

## Updating

- Updating from inside clark works from 1.0.4 to this version. To move from 1.0.3 or earlier to 1.0.5, install by hand as described under Known limits.
