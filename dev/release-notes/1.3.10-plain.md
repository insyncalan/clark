# clark 1.3.10, Mac

This is a polish release on 1.3. It is a full release.

## What is new

### Classic

- Documents and links (Edit): under the list there is a dashed drop area. A file dragged over it reads "Drop a file here to add it.", and under it the line "Dropped files are kept in the client folder, in Report files." A dropped file is added the same way as through the file window: PDF, Word, Excel, PowerPoint, JPG, PNG or TXT only, up to 25 MB. A larger file says "That file is larger than 25 MB, so it was not added."; several files, or a folder, say "Drop one file at a time." Cards has no drop area. [1275]
- Dashboard, Work items sections (View and Edit): "Show all items" and "Review all N items" sit on one footer line, "Show all items" at the left and "Review all N items" at the right. Two half-width sections side by side keep their footers level; at 900 px wide the sections stack and each has its own footer line. A published file has neither link. [1475]
- Ask clark: the tip in the box now says "Type / in the box for slash commands." and the box's hint reads "(type / for slash commands)"; both said "shortcuts" before. [1541]
- Classic, Published reports page (from the profile menu): one flat page with a single heading and a line-divided list, with no cover band or framed card; the date picker shows only in Cards. [1253]

## Behind the scenes (no change you see)

- Tests only: fixes and failure notes for the macOS test runs, so that a failing run says what the page showed [1515, 1552, 1554, 1556, 1558, 1559, 1560, 1287]; a test file that is stopped for running too long now leaves a process listing and Python tracebacks behind [1566].

## Known

- The macOS test runs for this release did not all finish: some shards were stopped at the 60-minute limit, and some tests failed or were stopped at their time limit. These are open and tracked [1598, 1599, 1600, 1601]; none of them is a change you see in clark.
