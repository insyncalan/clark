# clark 0.5.3 (Beta), Mac

Beta means the whole of clark is Beta until version 1.0.

Theme: a use case can be marked Done, which includes a database change.

## Read this first: a database change

- The data format changes (migration step 11): a use case can now be marked Done, a fourth status beside On track, Flag and High risk. A safety copy of the data is made before the change.
- An older clark refuses the new database (it says the data needs a newer clark). Once this version has opened a data folder, open it only with this version or newer. A manual install of an older version cannot open it. To go back, restore the safety copy.
- This update changes how your data is kept, so the Install button in Settings will not install it: download it and install it by hand.

## What is new

- Done: a use case can be marked Done. It shows in grey with its own word, sorts last and does not count as flagged. Excel lists it and reads it back unchanged, and the published page shows it.
