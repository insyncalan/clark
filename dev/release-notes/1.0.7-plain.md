# clark 1.0.7 (Beta), Mac

This is the 1.0 build. It is still marked Beta: it works and is tested, but expect rough edges and changes between versions.

## What is new

### Settings

- Settings has a Quit card. Press "Quit clark" and clark asks "Quit clark now?" with Quit clark and Cancel. After you confirm, clark stops, saying "Stopping clark. You can close this window." The card also says how to start it again: double-click clark.command in the clark folder (with Docker, start it the way you did before). Nothing is left running, so you do not need a Terminal window to end it. If it does not work, the card says "Quitting did not work. Try again."
- Settings has a Feedback card: a box for what is wrong or what you suggest, an optional contact line, and an "Open in your mail app" link. "Copy as text" is there for text that is too long for a link. clark sends nothing itself.

### Work items

- In the peek of an action, "Show history" under Latest update lists the changes to that one field, newest first. About five are in view and the rest scroll. The button reads "Hide history" while it is open.
- Filter tabs can be dragged left or right: pick a tab up with the mouse and let go where you want it, and the order is kept. The tab menu has Rename view, Move view, Duplicate view and Delete view. Move view lets the arrow keys move the tab. Delete view asks nothing first and gives a message with Undo.
- You can change a column's width by dragging the right edge of its heading, in the Milestones list, the Use cases list and the other tables; Alt+Left and Alt+Right do it from the keyboard.

### Help

- Help has a new guide, "The brand kit guide": what a brand kit holds, the limits (50 files, 16 MB the zip, 24 MB unpacked, 5 MB a file) and how to install one from Settings.

### Dashboard

- A new Dashboard section, Table, draws only the plan's table (the lines whose eye is on), full page or half page. It does not need the client Gantt switch, and Word leaves it out.

## What is changed

### Settings

- The Asking card in Settings says where a question goes and which account pays for it. The ask clark panel no longer carries that sentence.
- A brand's cover picture now shows faintly behind every page, under the top bar on the right, and at the foot of the ask clark panel. Text stays easy to read. With no cover picture nothing changes, and print has none.
- Each project now uses its own brand in everything clark makes: the web page, the preview, the Excel and Word files and the PDF. Two projects with different brands no longer take each other's colours and picture. A project on Generic, or whose brand has been removed, gets the plain look.
- The window that asks what to import opens with the sheets you ticked last time ticked. The first time, or if none of them is in the workbook, every sheet is ticked.
- When the folder window cannot open, Choose folder says so, and a box lets you type the folder's location and press "Add folder". In Docker it says the window needs the Mac.
- Spacing is one setting for the whole app: Compact (the usual look) or Comfortable, in Settings under Personal. The published report uses it too.
- Published reports is now a page of its own, with the brand, reached from the profile circle. It replaces the card in Settings.
- The Brands card takes a brand zip of any file name; the brand's own manifest names the brand. A red error line can be dismissed.

### Dashboard

- The Use case summary shows the first 5 use cases, with "Show all N use cases" and "Show the first 5" under the list. The count and the meter still cover every use case.
- On a use case's page you can link the use case straight to a milestone with "Link a milestone", and take the link away with "Unlink". Each is one step with Undo and a line in History, and the links go into the Excel workbook.
- In an opened use case row, each next step shows at most two lines, and clicking a step opens its peek.
- Risks and issues, Open actions and Decisions show one line for each item: a small tinted square with a letter for the kind (R, I, A or D) and a colour for the status, then the title, owner, date, priority and id. A long title is cut with dots and a click opens its peek. In a published file the status is also written as a word beside the icon.
- The use case Commitment choice that said Candidate now says "Planned 2026". Use cases that had Candidate are changed to it when clark opens your data, and old lines in History keep the old word.
- On a use case's page you can add and remove milestones of that use case. Each is one step with Undo. A published file shows them without the controls.
- On a use case's page, the Work items card shows one line for each item: id, title, one tinted status chip, then owner and due date in muted text.
- The Use cases page now follows the Work items page: four tabs over a filter line, with Group by (Status, Commitment, On the dashboard or Nothing), and Import, Export and Add use case on the same row.

### Published file

- In a published file, a use case opens its own page, read only, with its next steps as work items and its milestones. It has no History and no controls.
- In a published file, the At a glance tiles that count work items open the Work items page showing what they count, when the file has a Work items page.
- In a published file, a milestone's row, mark or chip opens a read-only peek.
- A published file no longer has the Weekly snapshot tab. It lists Dashboard, Work items, Milestones and Use cases (and Gantt where it is on). An old address for the snapshot opens the Dashboard.

### Work items

- The type buttons (All, Actions, Risks and issues, Decisions) and the status buttons (Open, Closed, All) above the list are gone in the app. Use type:, is:open, is:closed or status: on the filter line.
- "+ New view" makes a view at once, named View 1, View 2 and so on; you can rename it.
- Each choice in a drop-down of the peek, the table cells and the milestone peek shows a small icon beside its words, in the choice's colour where it has one. A milestone's Workstream is now a menu like the others.
- A message at the foot of the page goes after 5 seconds, with a thin bar that shrinks to show the time left. Pointing at it or Tabbing into it holds the time. Ctrl+Z still undoes the last change afterwards. With Reduce motion on there is no bar.
- Change owner in an item's menu has a search box over the people clark holds, and a name that is new can be added as a person and made the owner in one step with Undo.
- Group by is now one icon button, the same size as the Table and Board icons beside it. Its tooltip reads "Group by".
- The peek of a work item is flatter, with no tiles and a plain Latest update. The words box is headed "Ask clark to update for you", the Draft chip is gone, and Source shows only the file's name, in a published file too.
- The Table, Board and Group by icons now follow the clear button on the filter line, so the view tabs have the whole row and "+ New view" sits beside them.

### Opening clark

- clark now opens as a page in an ordinary Chrome window, at http://clark.localhost:8766/ (the port may differ), not in a window of its own. Chrome keeps what a page remembers for each address, so the views you saved and the other small choices clark keeps in the browser start again once, because the address is new. Your projects are not touched.

### Milestones

- In the Milestones list, a light line and a little space separate each milestone from the next.
- The milestone peek has the same format as the work item peek, and a published file shows the client's wording in it.

### Top bar and menu

- The top bar no longer shows the project name. The arrow beside the logo opens the project list, and there is more room between the logo and the top menu items.
- Import from Word is no longer in the profile circle's menu. Export to Word stays.
- Settings is in the profile circle's menu again, and the project button's menu lists only projects.

## What is fixed

### Work items

- In a work item's peek, the box for your words stays at the bottom while the peek scrolls.

### Excel

- In the Excel file, the Where it stands of a use case is its words in the cell, with no HTML tags.

### Published file

- A published page no longer shows a "Needs from you" section that the Dashboard in the editor does not have.

### Dashboard

- Half-width cards (Risks and issues, Open actions) now fit their rows in View and in Edit, and View reads the item's description on one line.

### Asking

- clark now finds Claude and Codex installed with npm or nvm (and the Intel Mac build of Codex). When it finds one it cannot use, it says so plainly and says how to install it again.

## Known limits

- Editing a demo project keeps it: Remove demo data takes away only the demo projects you have not touched.
- A Gantt sheet with more than 500 lines stops the import; split it into smaller sheets.
- The client workbook is a copy for the client. It cannot be imported back.
- Sorting is blocked on a protected sheet.
