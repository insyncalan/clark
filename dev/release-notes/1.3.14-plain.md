# clark 1.3.14, Mac

This is the last release on 1.3. It is a full release for the rows listed below. macOS: see the cut record.

## What is new

### Classic

- Dashboard: the default Dashboard has ten sections, with the Report headline first and work items lists for risks, actions and decisions. Its pill and chip text keeps a contrast of at least 4.5 to 1, in light and dark. [1266]
- Excel export: locked cells are grey, the sheets take the page colours, the headings are new, and there are Report and Documents sheets. The client's copy, made from the published report, has no Latest update column. [1390]
- Text style menu: in the toolbar and in the selection bubble, every row is 32 px high with one text size for all four lines, and the tick shows the current style. [1431]

## Known limits

- Pages you add and mark "Shown to the client" do not appear yet in the published report: it has no tab for them, though their content is saved inside the file.
- The client's Excel copy has no Documents sheet for the Documents section that new reports start with; reports that use the older Supporting Documents section still get one (#1683).

## Behind the scenes (no change you see)

- ask clark's file index: tests now pin how it reads damaged or hostile Office files. [1568]
- Release checks: every release run includes the Mac smoke set and reports it; a red smoke result never stops the release. [1602]
