# clark 1.0.8 (Beta), Mac

This is the 1.0 build. It is still marked Beta: it works and is tested, but expect rough edges and changes between versions.

## What is new

### Settings

- The Brands card in Settings has a picker for each project: Generic or any installed brand, with Undo, and a project whose brand was removed shows Generic with a note.
- Settings has a Search settings box, an Essentials card first, a changed dot with a Reset button on a setting that is not at its default, and Brand, Appearance, Spacing and Logging level save at once with an Undo.

### Work items

- Each work item row has a More actions button (shown on hover or focus, always on touch) that opens the row menu, and the peek has a More actions menu with Duplicate, Archive and Delete last in the warning colour; Delete asks the same question and offers Undo as before.

### Milestones

- A use case or a milestone can be deleted from its More actions menu, with Undo; one that something still refers to cannot be deleted, and clark says what refers to it.
- The Milestones Timeline has Week, Month and Quarter, and hides names that have no room.

### Published file

- A published file's Milestones list keeps the Hide details toggle (open when you arrive), and its Use cases tab has the editor's Sort by, Group by and tabs with counts, read only.
- The published report has a small moon and sun button beside the profile circle that switches between light and dark; the Light, Dark and System rows are gone from its menu.

### Dashboard

- The report band on the Dashboard shows the brand's logo at the right, and nothing when the brand has no logo.

### Docker

- Starting clark with Docker (bash docker/start.command) now stops before the container starts when the data folder was written by a newer clark, and says which folder, both data versions and how to use another folder; bash docker/diagnose.command shows the data folder, what is in it, both versions, the container and its last log lines.

## What is changed

### Settings

- The Excel file layout box on the Data card now says the Cover sheet holds the report as the page shows it, and lists the Gantt sheet too.

### Work items

- One-line wording fields (the Client wording on a row, picture captions, Movement words and the Own words of risks and issues) have no / menu and no formatting buttons, and Enter saves.
- The filter field no longer gets a purple highlight when the cursor is in it, and the icons stay in their place beside the box instead of inside it.
- Work item titles in lists and cards are now in normal weight, not bold.
- The Import and Export arrow buttons are gone from the Work items, Use cases and Gantt pages; import and export are in the profile circle menu and in Settings, in the Data card.
- Work item lists show the small tinted letter icon alone in the Status column, with no status words beside it, the same on the Work items page, a use case's page and a published file.

### Help

- Help has new lines for Quit clark, Docker and the Mac-only 'If a button says' line, and Help lines keep a readable width.
- The Quit entry in Help now names the question it asks, "Quit clark now?", with Quit clark to confirm and Cancel to stay, and says the page tells you how to start clark again.
- Help lines are narrower and easier to read, including the Start here return line.

### Dashboard

- On a use case's page the Milestones card has one button, Add a milestone, which links the use case to a milestone; a milestone that comes through work items has no Remove.
- In the Use case summary the row of coloured bars sits at the right end of the tile, on the same line as the counts.
- On the Dashboard the section tiles are now as wide as the report header, and a tile heading is smaller (19 px, 18 px in Compact).
- The Needed from the client switch and the Needs from you section are gone from the page; a stored Needs section stops showing and is not deleted.

### Use cases

- The Use cases page and the published Use cases tab now show each use case as the dashboard summary row does: the reference boxed once as "UC 1.1", the title, where it stands, the status and the number of next steps, with Sort by beside Group by.

### Published file

- Quotes, link previews, Help notes and the draft-email internal note no longer have a coloured bar down one side; they sit on a plain grey panel or a thin line, while amber, red and blue attention and selected bars stay.
- In a published file, the peek of a work item shows the Client wording, and for an action the Latest update, as read-only rows, and Esc on a use case page goes back to the Use cases list.
- The published report has one slim bar at the top that stays in view as you scroll, holding the project name, the tabs, the As at date and the profile circle.

### Excel

- The Excel export file is named with the project name, the code in brackets, then the date and time, for example Name(CODE) 2026.11.13 18.52.07.xlsx.
- In the Excel export, a Milestone drop-down cell now shows the milestone's name and a Use case cell shows its reference and title, such as "UC 1.5 Title", with no ids, and import still reads older cells.
- When a workbook names a milestone or use case that clark does not know, the import lists it and asks you to create it or use an existing one, and Import stays off until each is answered.
- On the Use cases sheet the column headed "Shown as" is now headed "Reference" and sits between ID and Use case, and a workbook headed "Shown as" still imports.

### Opening clark

- When there is only one project, clark opens it straight away, and with several it opens the one you used last on this computer; otherwise the project chooser still shows.

### Top bar and menu

- Every drop-down menu now shows an icon beside each line, as the Work items and Milestones menus already did.

### Asking

- When ask clark cannot read a PDF it now says why, and a source from a PDF reads 'name, page N'.

## What is fixed

### Settings

- Export to Word and Import from Word, opened from the Data card in Settings, now give focus back to the button that opened them when closed.
- A brand you have installed can now be attached to a project in the Brands card; before, a project could only show Generic.

### Work items

- Bulk Reopen no longer changes Delayed or Cancelled items to Open, and bulk Close no longer turns Cancelled items into Closed; those items are left out and a Cancelled item says it stays cancelled.
- The sideways two-finger swipe goes Back and Forward again over the board.
- A risk's tooltip now says Risk, Urgent or Risk, Red, never Red and Urgent together.

### Help

- The Help article on writing and formatting text no longer promises AI in the bubble bar, toolbar or command menu, and lists exactly what the editor has.

### Asking

- The Open Settings link in the ask clark box, when no model is connected, now takes you to the Asking card in Settings and stays there.

### Excel

- Every locked column of the Excel file now has the grey fill.

## Known limits

- Editing a demo project keeps it: Remove demo data takes away only the demo projects you have not touched.
- A Gantt sheet with more than 500 lines stops the import; split it into smaller sheets.
- The client workbook is a copy for the client. It cannot be imported back.
- Sorting is blocked on a protected sheet.
