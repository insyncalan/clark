# clark 1.3.4, Mac

This is a fix and polish release on 1.3. It is a full release.

## What is new

### Classic
- The section bands follow the sections that are visible, so hiding a section leaves no wrong band.
- The Ctrl/Cmd+K quick bar list has roomier rows with the name, a short hint and the kind, and a taller input.
- A menu never opens under the sticky page header; it keeps clear and scrolls inside the room left.
- Menu panels have 10 px corners, and the Settings menu panel is soft grey.
- The Add menu draws the + icon.
- The ask clark page tabs are 29 px pills; the first-use card and status line are redrawn.
- Peeks open 62% of the page wide (at least 300 px).
- Work items grouped view: a heading line, column names once, flat rows. The layout switch has 8 px corners.
- The Dashboard layout has its title block, page padding, heading line and section padding as designed; the Use cases list is drawn as the design shows.
- The Gantt plan runs the width of the page band in Comfortable spacing.
- Peek: no focus ring on Close when a peek opens without a key; a decision shows "made by" and "needed by" / "made on".
- Priority colour is one mapping: Low green, Medium amber, High red, Urgent maroon.
- Edit shows a text tag on a hidden Tile or Heading.
- No tooltip on Add item, Add action, Add milestone, Add use case, Add project.
- The Add to the weekly report suggestion is back with the other item actions.

### Ask clark
- ask clark answers from the open project's own items, including items hidden from the report (archived ones are left out), and when it has to cut, the answer ends with a plain line saying what was left out.

### Settings
- Version and updates can check for the newest release, download it and cancel.
- Changes and safety: the words match the code; the connector security review and change gate are written down.
- Backup: the kept-copies decision is recorded and the restore is tested end to end.

### Dashboard and templates
- Key figures in Edit offers a live figure only while its section exists.
- The templates library no longer offers Risks and issues, Open actions or Decisions cards; an older document that has them still opens and exports.
- A change with no current title is refused.

### Word
- The Word export writes a callout's category, colour and icon.

### Help
- Help says where the Legend is, what Accept all does, the System theme, which sheets start ticked, that 300 changes are listed, Import answers, peek More actions, weekend and overdue, Latest update and the Legend choice.

## Known limits
- On Use cases, Commitment, Release and On the dashboard all on at once leave the Use case column too narrow; turn one off.
