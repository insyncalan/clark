# clark 0.10.0 (Beta), Mac

Beta means the whole of clark is Beta until version 1.0.

Theme: Settings, About you says what was saved, with Undo. The rest of this version is behind the scenes so far (re-read at the cut against what has merged).

## What is new

- Nothing new that you can see yet.

## What is fixed

- Settings, About you: saving the name or the email now says what was saved ("Name saved.", "Email saved.", "Name cleared."), with an Undo that puts the old value back in the box, the menu and the saved data. Typing again takes the Undo away, and saving the same words again says nothing.

## Behind the scenes

- Tests and notes only: one shared growth check in the tests, the notes on which links to documents are turned away now name every ending and number range, and a request for an AI suggestion must say whose it is so that Stop can end it.
