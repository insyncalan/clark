# clark 0.10.0 (Beta), Mac

Beta means the whole of clark is Beta until version 1.0.

Theme: small fixes and tidy-ups after 0.9, found in the reads and checks.

## What is new

- Text boxes where you write sentences (ask clark, the Dashboard Current state and glance boxes, the movement notes, the peek's Latest update, people and note boxes, link cards and the like) open at three lines, grow as you type with one blank row always under the last line, and have a handle in the bottom right corner to pull the box taller by hand. A one-line field such as a title or a name stays one line.
- The clark name in the top bar is a little larger, the same size as a section heading, and the project name shortens first when the bar is tight.

## What is fixed

- With no project open, Settings now opens, so the first project can be added with Add project in Edit (before, a new install, or Docker with empty data, showed only "No project open"). Import workbook shows there but is greyed until a project exists.
- If a publish replaces a link and the old report cannot be put back, clark now says so: "The old report could not be put back in the folder. It is still there under a hidden name." If the old copy cannot be cleared it says "The old copy could not be cleared.". A file that is not clark's own is never removed.
- After an update, Undo update now takes the data copy made when the update started, never a newer copy of another layout; with no right copy it refuses, so the wrong data is never put back.
- A notice that appears while a box is open is held back with the page behind it, so it cannot be clicked through, and it is let go when the box closes.

## Behind the scenes

- Tests and checks only: an imported workbook's links are checked never to be fetched or opened; the report bar's hooks sit above its early return; the shared growth check has a limit of 6.5 after the hosted macOS runners read healthy ratios above the old one; test notes in three tests were corrected.
