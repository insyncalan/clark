# clark 1.3.8, Mac

This is a polish release on 1.3. It is a full release.

## What is new

### ask clark

- On an answer you can use Copy and Ask again, and press the Up arrow in the question box to bring back your previous question. [1292]
- ask clark addresses you by the name saved in your profile; nothing is sent when the name is empty, and the Ask settings card shows a privacy line while a name is saved. [1331]
- With Files turned off, dropping a file on the ask clark panel no longer opens the file in the browser. [1506]

### Dashboard, Reports and Templates

- A published use case page has the same layout as the use case page in the editor, read only: the Owner is shown, there is no History card and no Last change. [1479]

### Editor

- The rich text editor has a font colour button after Strikethrough, in the toolbar and in the bubble, with Automatic and a set of named colours; the colour is kept in published files and in Word exports (Excel stays plain words). [1364]

### Milestones and Work items

- The Milestones page no longer shows the "forecast" sentence or the Plan | Movement switch with its text. [1329]
- The Columns menu on Work items looks like the approved design: the heading "Columns to show" and one line per column with a tick. [1499]
- On the Milestones Calendar view the Timeline / Calendar switch no longer overlaps the Earlier, Later and Today buttons. [1507]

### Settings and look

- The text box in the Feedback panel fills the width of the panel, level with the "Added automatically" box. [1334]
- The Settings sidebar groups have the same spacing between 900 and 1099 pixels wide as on wider screens. [1500]

## Tests and internal

Test fixes for macOS (rows 1277, 1521, 1522), a test pinning the width of the Work items Edit filter line (1340, 1511), a test pinning markdown marks in the quoted "From your file" passage (1278), and a spike on how ask clark reads a library (1368). Nothing a person sees.
